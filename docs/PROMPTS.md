# Prompt log

Every prompt given to an AI assistant while building this project, with the model and what was done with the output.
Runtime prompts the pipelines send to Claude (optional) are logged automatically to `data/artifacts/prompts.jsonl`.

| # | Model | Prompt (verbatim or summarized) | What was done with the output |
| --- | --- | --- | --- |
| 1 | Claude Fable 5.1 (Claude Code) | "look at the file thats there, we are gonna work on P4 AND P6. we need to make it like a proper enterprise platform with sidebar and all" | Model read the project guide, probed public sources, designed the data model/API contract, scaffolded backend and frontend, then built the P4 and P6 modules and UI pages in three parallel sub-agents. All code was reviewed by running the pipelines end-to-end and clicking through the UI. |
| 2 | Claude Fable 5.1 (Claude Code), sub-agents | Three parallel build briefs written by the main session: (a) P4 module: collectors, fetch, features, two-stage clustering, kit signatures, Sigma/YARA/IOC/STIX outputs, API, tests, live run; (b) P6 module: ransomware.live + ransomwatch ingestion, sector/region/size classification, cross-source matching, actor stats, IAB mining from RSS, Jinja2 briefing, API, tests, live run; (c) all frontend pages against a fixed TypeScript contract, verified in a browser. | Each sub-agent's report was checked against the code and a live run before integration. Bugs they surfaced (recursion on deep DOMs, tools-as-dict from ransomware.live, SQLite lock contention, stale-run recovery killing a live CLI run) were fixed in the main session. |
| 3 | Claude Opus 5.5 (Claude Code) | "we have a project called the mintverse, please adapt the design of that for this project. the present design doesnt look good. also we need a lot of good visualisations" | Model read the Mintverse React app (tokens, ECharts theme, ChartCard, KpiTile, shell, command palette), ported the design system and chart layer, wrote a library of ECharts builders (calendar and matrix heatmaps, Sankey, network graph, stream, bump, world map, radar, funnel, gauges, box plot), then two sub-agents rebuilt the P4 and P6 pages and added one aggregate viz endpoint per module. |
| 4 | Claude Opus 5.5 (Claude Code) | Hand check: "sample 12 in-scope victims and the 12 largest campaigns, mark agree / over-flag / miss" (run by the model as SQL over the clean-start database, judged by reading each record) | Results in the report's hand-check table. Findings that change the pipeline (legitimate-domain allowlist, hosting-template blocklist) are listed as next steps, not applied silently. |
